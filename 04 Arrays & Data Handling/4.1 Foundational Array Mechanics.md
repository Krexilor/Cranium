## Overview
An **array** is a fixed-size collection of elements of the **same data type**, stored in **contiguous memory locations**. Arrays are the foundation for almost every data structure built later in this curriculum.

## Declaring & Initializing Arrays

```cpp
// Declaration with fixed size
int scores[5];

// Declaration + initialization
int scores[5] = {85, 92, 78, 90, 88};

// Size inferred from initializer list
int scores[ ] = {85, 92, 78, 90, 88};     // size becomes 5 automatically

// Partial initialization - remaining elements default to 0
int scores[5] = {85, 92};     // {85, 92, 0, 0, 0}

// All elements zero-initialized
int scores[5] = { };     // {0, 0, 0, 0, 0}
```

> [!WARNING]
> Unlike `std::vector`, a raw array's size is **fixed at compile time** (when declared without `new`) and cannot grow or shrink. If you need a dynamically resizable collection, use `std::vector` (covered in STL) instead.

## Accessing Array Elements
Arrays use **zero-based indexing** - the first element is at index `0`, not `1`.

```cpp
int scores[5] = {85, 92, 78, 90, 88};

std::cout << scores[0] << std::endl;     // 85 (first element)
std::cout << scores[4] << std::endl;     // 88 (last element)

scores[2] = 100;               // modify the 3rd element
std::cout << scores[2] << std::endl;     // 100
```

> [!WARNING]
> C++ does **not** perform automatic bounds checking on raw arrays. Accessing `scores[5]` (out of bounds for a 5-element array) is **undefined behavior** - it may silently read garbage memory, corrupt other data, or crash, with no compiler error. This is of the most common sources of bugs in C/C++.

## Finding Array Size
Raw arrays don't store their own length - you must track or calculate it.

```cpp
int scores[5] = {85 ,92, 78, 90, 88};

int size = sizeof(scores) / sizeof(scores[0]);
std::cout << "Array size: " << size << std::endl;     // 5
```

> [!NOTE]
> `sizeof(scores)` returns the **total bytes** used by the array, while `sizeof(scores[0])` returns the bytes used by a single element. Dividing them gives the element count. This trick only works on raw (stack-allocated) arrays - it fails once the array decays to a pointer (e.g., inside a function parameter).

### `std::size` and `std::ssize` (C++17 / C++20)
The standard library has a safer way to ask an array for its length:

```cpp
#include <iterator>

int scores[5] = {85, 92, 78, 90, 88};

std::cout << std::size(scores) << "\n";          // 5 (type size_t, unsigned)
std::cout << std::ssize(scores) << "\n";         // 5 (C++20, signed - convenient for loops using int)
```

> [!NOTE]
> Unlike the `sizeof` trick, these functions refuse to compile when given a pointer, so a decayed array cannot silently give a wrong answer: `size(ptr)` fails with `no matching function for call to 'size(int*&)'`. The same functions also work on `std::array` and `std::vector` (4.6), so they are useful beyond raw arrays.

## Iterating Through an Array

```cpp
int scores[5] = {85, 92, 78, 90, 88};

// Traditional for loop
for (int i = 0; i < 5; i++) {
    std::cout << scores[i] << " ";
}

// Range-based for loop (C++11) - cleaner, no index management
for (int score : scores) {
    std::cout << score << " ";
}
```

The loop variable in a range-based `for` is a **copy** by default:

```cpp
// Modifies a copy - the array is NOT changed
for (int score : scores) {
    score += 1;
}

// Use a reference to modify the elements in place
for (int& score : scores) {
    score += 1;                        // scores is now {86, 93, 79, 91, 89}
}

// Use a const reference to avoid copying large types
std::string names[3] = {"Alice", "Bob", "Charlie"};
for (const std::string& name : names) {
    std::cout << name << " ";
}
```

## Single-Dimensional Array Operations

### Sum & Average

```cpp
int scores[5] = {85, 92, 78, 90, 88};
int sum = 0;

for (int i = 0; i < 5; i++) {
    sum += scores[i];
}

double average = (double)sum / 5;
std::cout << "Sum: " << sum << ", Average: " << average << std::endl;
```

### Finding Maximum / Minimum

```cpp
int scores[5] = {85, 92, 78, 90, 88};
int maxVal = scores[0];
int minVal = scores[0];

for (int i = 1; i < 5; i++) {
    if (scores[i] > maxVal) maxVal = scores[i];
    if (scores[i] < minVal) minVal = scores[i];
}

std::cout << "Max: " << maxVal << ", Min: " << minVal << std::endl;
```

### Linear Search

```cpp
int scores[5] = {85, 92, 78, 90, 88};
int target = 78;
int foundIndex = -1;

for (int i = 0; i < 5; i++) {
    if (scores[i] == target) {
        foundIndex = i;
        break;
    }
}

if (foundIndex != -1) {
    std::cout << "Found at index: " << foundIndex << std::endl;
} else {
    std::cout << "Not found." << std::endl;
}
```

### Reversing an Array In-Place

```cpp
int scores[5] = {85, 92, 78, 90, 88};
int start = 0, end = 4;

while (start < end) {
    int temp = scores[start];
    scores[start] = scores[end];
    scores[end] = temp;
    start++;
    end--;
}

// Scores are now {88, 90, 78, 92, 85}
```

> [!TIP]
> The two-pointer swap pattern (`start`/`end` converging toward the middle) is a fundamental technique that reappears constantly in array and string algorithms - palindrome checks, sorting partitions, and more.

## Arrays of Other Types

```cpp
char grade[5] = {'A', 'B', 'C', 'D', 'F'};
double prices[3] = {9.99, 19.99, 29.99};
std::string names[3] = {"Alice", "Bob", "Charlie"};
bool flags[4] = {true, false, true, false};
```

> [!IMPORTANT]
> Every element in a C++ array **must be the same type**. To group values of *different* types into one record, use a `struct` (4.4). Arrays of structs, such as `Student roster[3]`, are a very common pattern.

## Limitations of Raw Arrays
Raw (C-style) arrays are fast and simple, but they are missing features you would expect:

| Limitation                          | Consequence                                                                                   |
| ----------------------------------- | --------------------------------------------------------------------------------------------- |
| Size fixed at compile time          | An array cannot grow or shrink. Runtime sizes need dynamic memory (Topic 5) or `std::vector`. |
| No size information after decay     | You must pass the size separately (4.3).                                                      |
| No bounds checking                  | An out-of-range index is undefined behavior.                                                  |
| Cannot be assigned or copied with `=` | `b = a;` does not compile.                                                                  |
| `==` compares addresses             | Two arrays with identical contents are "not equal".                                           |
| Cannot be returned from a function  | A function cannot return a raw array by value.                                                |

```cpp
int a[3] = {1, 2, 3};
int b[3] = {1, 2, 3};

// b = a;                              // ERROR: invalid array assignment
std::cout << (a == b) << "\n";              // 0: compares addresses, not contents
```

> [!NOTE]
> C++20 compilers warn about array comparison: `comparison between two arrays is deprecated in C++20`. To copy an array, copy the elements one by one with a loop.

`std::array` and `std::vector` (4.6) fix every item in this table while keeping array performance, and they are the preferred choice in modern C++. Raw arrays remain essential for understanding pointers, memory, and legacy or C code.
