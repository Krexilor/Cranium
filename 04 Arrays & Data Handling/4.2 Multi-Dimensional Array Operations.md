## Overview
A **multi-dimensional array** is an array - most commonly, a **2D array** is used to represent grids, matrices, tables, or game boards. C++ supports arrays of any dimension, though 2D and occasionally 3D are what you'll encounter in practice.

## Declaring & Initializing a 2D Array

```cpp
// Syntax: type name[rows][columns];
int grid[3][4];

// Declaration + initialization
int matrix[2][3] = {
    {1, 2, 3},
    {4, 5, 6}
};

// Flat initialization (less readable, same result)
int matrix[2][3] = {1, 2, 3, 4, 5, 6};
```

> [!NOTE]
>Conceptually, a 2D array is a grid - `matrix[row][col]`. Internally, C++ still stores it as one continuous, contiguous block of memory (covered in detail in the next file or Array Memory Layout).

## Accessing 2D Array Elements

```cpp
int matrix[2][3] = {
    {1, 2, 3},
    {4, 5, 6}
};

std::cout << matrix[0][0] << std::endl;     // 1 (row 0, col 0)
std::cout << matrix[1][2] << std::endl;     // 6 (row 1, col 2)

matrix[0][1] = 100;               // modify row 0, col 1
std::cout << matrix[0][1] << std::endl;     // 100
```

> [!WARNING]
>Just like 1D arrays, there is **no bounds checking**. Accessing `matrix[5][10]` on a `[2][3]` array is undefined behavior, not a clean error.

## Iterating a 2D Array
Requires **nested loops** - the outer loop walks rows, the inner loop walks columns.

```cpp
int matrix[2][3] = {
    {1, 2, 3},
    {4, 5, 6}
};

for (int row = 0; row < 2; row++) {
    for (int col = 0; col < 3; col++) {
        std::cout << matrix[row][col] << " ";
    }
    std::cout << std::endl;
}

/*
Output:
1 2 3
4 5 6
*/
```

## Common 2D Array Operations

### Sum of All Elements

```cpp
int matrix[2][3] = {{1, 2, 3}, {4, 5, 6}};
int total = 0;

for (int row = 0; row < 2; row++) {
    for (int col = 0; col < 3; col++) {
        total += matrix[row][col];
    }
}
std::cout << "Total: " << total << std::endl;     // 21
```

### Row Sums and Column Sums

```cpp
int matrix[2][3] = {{1, 2, 3}, {4, 5, 6}};

// Sum of each row
for (int row = 0; row < 2; row++) {
    int rowSum = 0;
    for (int col = 0; col < 3; col++) {
        rowSum += matrix[row][col];
    }
    std::cout << "Row " << row << " sum: " << rowSum << std::endl;
}

// Sum of each column
for (int col = 0; col < 3; col++) {
    int colSum = 0;
    for (int row = 0; row < 2; row++) {
        colSum += matrix[row][col];
    }
    std::cout << "Col " << col << " sum: " << colSum << std::endl;
}
```

### Matrix Transpose
Swapping rows and columns - `matrix[row][col]` becomes `result[col][row]`.

```cpp
int matrix[2][3] = {{1, 2, 3}, {4, 5, 6}};
int transposed[3][2];     // dimensions flipped

for (int row = 0; row < 2; row++) {
    for (int col = 0; col < 3; col++) {
        transposed[col][row] = matrix[row][col];
    }
}

/*
Output:
1 4
2 5
3 6
*/
```

### Matrix Addition
Two matrices of identical dimensions, added element-wise.

```cpp
int a[2][2] = {{1, 2}, {3, 4}};
int b[2][2] = {{5, 6}, {7, 8}};
int result[2][2];

for (int row = 0; row < 2; row++) {
    for (int col = 0; col < 2; col++) {
        result[row][col] = a[row][col] + b[row][col];
    }
}

/*
Output:
6 8
10 12
*/
```

### Three-Dimensional Arrays
For completeness - a 3D array adds a third index, often visualized as "stack of grids."

```cpp
int cube[2][2][2] = {
    { {1, 2}, {3, 4} },
    { {5, 6}, {7, 8} }
};

std::cout << cube[1][0][1] << std::endl;     // 6

for (int x = 0; x < 2; x++) {
    for (int y = 0; y < 2; y++) {
        for (int z = 0; z < 2; z++) {
            std::cout << cube[x][y][z] << " ";
        }
    }
}
```

> [!TIP]
> Beyond 2D, multi-dimensional arrays become rare in everyday code. 3D+ structures are typically modeled with `std::vector<std::vector<std::vector<T>>>` or flattened 1D arrays with manual index math, both of which offer better flexibility than raw nested arrays (see 4.6).

## Passing 2D Arrays to Functions
A 1D array decays to a pointer when passed to a function (4.3). A 2D array does too, but only the **outermost** dimension decays, so the function must still be told every other dimension:

```cpp
constexpr int COLS = 3;

void printMatrix(const int m[][COLS], int rows) {     // the first dimension may be omitted
    for (int r = 0; r < rows; r++) {
        for (int c = 0; c < COLS; c++) {
            std::cout << m[r][c] << " ";
        }
    }
    std::cout << "\n";
}

int main() {
    int matrix[2][3] = {{1, 2, 3}, {4, 5, 6}};
    printMatrix(matrix, 2);                           // 1 2 3 4 5 6
}
```

### Why the Column Count Is Required
Memory is row-major (4.3), so `m[r][c]` is computed as `base + (r * COLS + c) * sizeof(int)`. Without `COLS` the compiler cannot find where each row starts:

```cpp
void bad(int m[][]) { }
// ERROR: declaration of 'm' as multidimensional array must have bounds
//        for all dimensions except the first
```

### What the Parameter Really Is
`int m[2][3]` decays to a **pointer to a row of 3 ints**, written `int (*)[3]`. These two declarations are identical:

```cpp
void printMatrix(const int m[][COLS], int rows);
void printMatrix(const int(*m)[COLS], int rows);
```

so `sizeof(m)` inside the function is the size of a pointer (8), not of the matrix. The number of rows must be passed separately.

### Keeping the Size with a Reference
A reference to the whole array prevents decay and preserves every dimension, but it only accepts that exact shape:

```cpp
void printShape(const int(&m)[2][3]) {
    std::cout << sizeof(m) << " " << std::size(m) << " " << std::size(m[0]) << "\n";     // 24 2 3
}
```

> [!NOTE]
> Writing one function that accepts *any* dimensions needs templates (Topic 10). In practice, `std::vector<std::vector<int>>` or `std::array` (4.6) solves this far more simply.
