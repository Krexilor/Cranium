## Overview
C++ has two ways to represent text:

| Kind            | What it is                                         | When to use it                                                 |
| --------------- | -------------------------------------------------- | -------------------------------------------------------------- |
| **C-string**    | A `char` array ending in a null terminator `'\0'`  | Understanding string literals, C libraries, and low-level code |
| **std::string** | A standard library class that manages its own text | **Default choice** for all normal text handling                |

## C-Strings

### The Null Terminator
A C-string is an array of `char` whose last character is `'\0'` (the number 0). That terminator is how functions know where the text ends.

```cpp
char name[] = "Krex";                  // the compiler adds the terminator
```

```
Index:   [0]  [1]  [2]  [3]  [4]
Value:   'K'  'r'  'e'  'x'  '\0'
```

```cpp
std::cout << sizeof(name) << "\n";          // 5 (includes the terminator)
std::cout << strlen(name) << "\n";          // 4 (counts characters BEFORE the terminator)

name[0] = 'k';                         // OK: name is a modifiable array
std::cout << name << "\n";                  // krex
```

```cpp
char a[4] = "Krex";                    // ERROR: initializer-string for 'char [4]' is too long
```

> [!WARNING]
> If the terminator is missing, `std::cout`, `strlen`, and every other C-string function keep reading past the end of the array until they happen to find a zero byte. That is an out-of-bounds read, which is undefined behavior (see 2.8).

### String Literals
A literal like `"Krex"` lives in **read-only memory** (see the memory layout in 5.5) and has the type `const char[5]`.

```cpp
const char* lit = "Krex";              // a pointer to the read-only literal
std::cout << sizeof(lit) << "\n";           // 8 (just the pointer's size on a 64-bit system)
std::cout << strlen(lit) << "\n";           // 4

// lit[0] = 'k';                       // ERROR: assignment of read-only location '*lit'
// char* bad = "Krex";                 // ill-formed since C++11; GCC only warns:
                                       // "ISO C++ forbids converting a string constant to 'char*'"
```

| Declaration                | What you get                                              | Modifiable?  | Can be re-pointed? |
| -------------------------- | --------------------------------------------------------- | ------------ | ------------------ |
| `char name[] = "Krex";`    | An array holding a **copy** of the text (5 bytes)         | Yes          | No                 |
| `const char* lit = "Krex";`| A pointer to the shared read-only literal                 | No           | Yes                |

### `<cstring>` Functions

| Function            | Purpose                                                          |
| ------------------- | ---------------------------------------------------------------- |
| `strlen(s)`         | Length, not counting the terminator                              |
| `strcmp(a, b)`      | Compares contents: `0` if equal, negative if `a < b`, positive if `a > b` |
| `strcpy(dest, src)` | Copies `src` (including the terminator) into `dest`              |
| `strcat(dest, src)` | Appends `src` to the end of `dest`                               |

```cpp
#include <cstring>

char s1[] = "abc", s2[] = "abc";
std::cout << (s1 == s2) << "\n";                    // 0: compares ADDRESSES, not text
std::cout << (strcmp(s1, s2) == 0) << "\n";         // 1: compares the contents

char buf[16] = "Hi";
strcat(buf, "!!");                             // "Hi!!"
char copy[16];
strcpy(copy, buf);                             // copy holds "Hi!!"
```

> [!WARNING]
> `strcpy` and `strcat` perform **no bounds checking**. If the destination is too small they write past the end of the array (a buffer overflow), a classic source of crashes and security vulnerabilities. Also, `std::cin >> charArray` has no length limit. If you must read into a `char` buffer, use `std::cin.std::getline(buf, sizeof(buf))`, which stops at the buffer size. When the line is longer than the buffer it keeps what fits and sets the stream's fail state (see 2.3).

## `std::string`

```cpp
#include <std::string>

std::string a = "Hello";
std::string b = a;                          // an independent copy
b += " World";
std::cout << a << "|" << b << "\n";         // Hello|Hello World
```

A `std::string` owns its characters on the heap, grows automatically, and frees its memory when it goes out of scope. It is the first example of a pattern called **RAII** that you will meet again in Topics 6 and 9.

### Common Operations

```cpp
std::string b = "Hello World";

std::cout << b.size() << " " << b.length() << "\n";     // 11 11 (same length)
std::cout << b.empty() << "\n";                         // 0 (false)
```

| Operation          | Example                       | Result / Notes                                                   |
| ------------------ | ----------------------------- | ---------------------------------------------------------------- |
| Index (unchecked)  | `b[0]`                        | `'H'`; an invalid index is undefined behavior                    |
| Index (checked)    | `b.at(1)`                     | `'e'`; an invalid index throws `std::out_of_range`               |
| First / last       | `b.front()`, `b.back()`       | `'H'`, `'d'`                                                     |
| Concatenate        | `a + ", " + "x"`              | `"Hello, x"`                                                     |
| Append             | `b += "!"`, `b.push_back('!')`| Adds to the end                                                  |
| Remove last        | `b.pop_back()`                | Removes the last character                                       |
| Repeat             | `std::string(3, 'x')`              | `"xxx"`                                                          |
| Substring          | `b.substr(6)`, `b.substr(0, 5)` | `"World"`, `"Hello"` (`substr(position, length)`)              |
| Find               | `b.find("World")`             | `6`, or `std::string::npos` if not found                              |
| Replace            | `b.replace(6, 5, "C++")`      | `"Hello C++"` (`replace(position, length, newText)`)             |
| Insert             | `b.insert(5, ",")`            | `"Hello, C++"`                                                   |
| Erase              | `b.erase(0, 1)`               | `"ello, C++"`                                                    |
| Compare            | `==`, `!=`, `<`, `>`          | Compares **contents**, lexicographically                         |

```cpp
std::string s = "Hello World";

std::size_t pos = s.find("World");
std::cout << pos << "\n";                                   // 6
std::cout << (s.find("zzz") == std::string::npos) << "\n";       // 1: not found
std::cout << std::string::npos << "\n";                          // largest possible std::size_t

std::cout << (std::string("apple") < std::string("banana")) << "\n";  // 1
```

> [!WARNING]
> `find` returns a `std::size_t`, never a negative number. Store the result in a `std::size_t` and compare it with `std::string::npos` to detect "not found".

> [!WARNING]
> `at()` throws an exception when the index is invalid. Exceptions are covered in Topic 8; until then, an uncaught one terminates the program with a message like:
> ```text
> terminate called after throwing an instance of 'std::out_of_range'
>   what():  basic_string::at: __n (which is 10) >= this->size() (which is 3)
> ```
> Plain `[]` does no checking at all and silently reads garbage (undefined behavior).

### Concatenation Pitfall

```cpp
std::string bad = "Hello" + " World";               // ERROR: string literals cannot be added
std::string ok = std::string("Hello") + " World";        // OK: one operand is a std::string
```

Two string literals are `const char` arrays, and arrays cannot be added. At least one side of `+` must be a `std::string`.

### Strings and Functions
* Pass by **`const std::string&`** for read-only access, and `std::string&` to modify the caller's string (3.2). Passing by value copies the whole text.
* Returning a `std::string` by value is cheap (3.2).
* `s.c_str()` returns a `const char*` to a null-terminated copy of the text, for functions that expect a C-string.
* `stoi`, `stod`, and `to_string` convert between strings and numbers (2.7). For example, `stoi("12 apples")` returns `12`, because it parses the leading number only.

> [!NOTE]
> A read-only, non-owning view of text (`std::string_view`) is covered in the STL topic.

## Working with Characters (`<cctype>`)

| Function          | Purpose                                  |
| ----------------- | ---------------------------------------- |
| `isdigit(c)`      | Is `c` a digit `0-9`?                    |
| `isalpha(c)`      | Is `c` a letter?                         |
| `isalnum(c)`      | Is `c` a letter or a digit?              |
| `isspace(c)`      | Is `c` whitespace (space, tab, newline)? |
| `isupper(c)` / `islower(c)` | Is `c` uppercase / lowercase?  |
| `toupper(c)` / `tolower(c)` | Converted character (as an `int`) |

> [!IMPORTANT]
> * The `is...` functions return a **non-zero value** for true, not necessarily `1`. Use them directly in conditions, or compare with `!= 0`.
> * The argument must be in the range of `unsigned char` (or `EOF`); passing a negative `char` is undefined behavior. Cast it: `static_cast<unsigned char>(c)`.
> * `toupper` / `tolower` return an `int`, so cast the result back to `char`.

### Worked Examples

```cpp
#include <cctype>

// Convert to uppercase in place (a reference lets the loop modify the string)
std::string a = "Hello";
for (char& ch : a) {
    ch = static_cast<char>(toupper(static_cast<unsigned char>(ch)));
}
std::cout << a << "\n";                             // HELLO
```

```cpp
// Count vowels
int vowels = 0;
std::string text = "Programming Language";
for (char ch : text) {
    char lower = static_cast<char>(tolower(static_cast<unsigned char>(ch)));
    if (lower == 'a' || lower == 'e' || lower == 'i' || lower == 'o' || lower == 'u') {
        vowels++;
    }
}
std::cout << vowels << "\n";                        // 7
```

```cpp
// Palindrome check
std::string word = "level";
bool isPalindrome = true;
for (std::size_t i = 0; i < word.size() / 2; i++) {
    if (word[i] != word[word.size() - 1 - i]) {
        isPalindrome = false;
    }
}
std::cout << isPalindrome << "\n";                  // 1
```

```cpp
// Reverse in place (std::swap from <utility>)
std::string rev = "stressed";
for (std::size_t i = 0, j = rev.size() - 1; i < j; i++, j--) {
    std::swap(rev[i], rev[j]);
}
std::cout << rev << "\n";                           // desserts
```

> [!WARNING]
> `rev.size() - 1` on an **empty** string wraps around to a huge `std::size_t` value (the unsigned trap from 2.2). Guard such code with an `empty()` check.

## C-String vs `std::string`

| Aspect              | C-string (`char[]`)                    | `std::string`                          |
| ------------------- | -------------------------------------- | -------------------------------------- |
| Length              | `strlen`, scans for `'\0'`             | `size()`, stored, instant              |
| Resizing            | Fixed array size                       | Grows automatically                    |
| Copy                | `strcpy` (unchecked)                   | `b = a`                                |
| Compare             | `strcmp`; `==` compares addresses      | `==`, `<` compare contents             |
| Concatenate         | `strcat` (unchecked)                   | `+`, `+=`                              |
| Bounds safety       | None                                   | `at()` is checked                      |
| Typical use         | Literals, C APIs, `argv`               | Everything else                        |

## Command-Line Arguments (Optional)
A program receives its command-line arguments as an array of C-strings:

```cpp
int main(int argc, char* argv[]) {
    std::cout << "argc = " << argc << "\n";
    for (int i = 0; i < argc; i++) {
        std::cout << i << ": " << argv[i] << "\n";
    }
    if (argc > 1) {
        std::string first = argv[1];        // convert to std::string for easy handling
        std::cout << first.size() << "\n";
    }
}

// Running:  ./app hello "two words"
// argc = 3
// 0: `./app` (`argv[0]` is the program's name)
// 1: hello
// 2: two words
// 5                                   (length of "hello")
```

`argc` is the number of arguments (always at least 1), and `argv` is an array of that many C-strings. Always check `argc` before reading `argv[i]`. The pointer syntax `char*` is explained in Topic 5.
