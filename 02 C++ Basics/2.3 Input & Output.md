## Overview
C++ handles console input and output through **streams** - abstract flows of data. The standard streams are provided by the `<iostream>` header.

| Stream | Direction | Purpose                       |
| ------ | --------- | ----------------------------- |
| `std::cout` | Output    | Print to the console          |
| `std::cin`  | Input     | Read from the keyboard        |
| `std::cerr` | Output    | Print errors (unbuffered)     |
| `std::clog` | Output    | Print log messages (buffered) |

## Output with `std::cout`
The `<<` operator (stream insertion) pushes data into the output stream.

```cpp
#include <iostream>
int main() {
    int age = 21;
    std::string name = "Krex";

    std::cout << "Name: " << name << std::endl;
    std::cout << "Age: " << age << std::endl;

    // Chaining multiple outputs
    std::cout << "Name: " << name << ", Age: " << age << "\n";

    return 0;
}
```

### `std::endl` vs `"\n"`
| `std::endl`                               | `"\n"`                                   |
| ------------------------------------ | ---------------------------------------- |
| Inserts newline + **flushes** buffer | Inserts newline only                     |
| Slightly slower                      | Faster (preferred in loops/heavy output) |

> [!NOTE]
> **Prefer \n over endl:** `std::endl` flushes the output buffer on every call, which is expensive in loops or high-frequency output. Use `"\n"` unless you specifically need to force a buffer flush.

## Input with `std::cin`
The `>>` operator (stream extraction) reads data from the keyboard into a variable.

```cpp
#include <iostream>
int main() {
    int age;
    std::string name;

    std::cout << "Enter your name: ";
    std::cin >> name;

    std::cout << "Enter your age: ";
    std::cin >> age;

    std::cout << "Hello, " << name << "! You are " << age << " years old." << std::endl;

    return 0;
}
```

> [!WARNING]
> **cin stops at whitespace:** `std::cin >>` reads only until the first space or newline. It will **not** capture a full name like "John Doe" - it stops at "John".
>

## Reading Full Lines with `std::getline( )`
Use `std::getline( )` to read an entire line including spaces.

```cpp
#include <limits>

int age;
std::cin >> age;
std::cin.ignore(std::numeric_limits<std::streamsize>::max(), '\n');   // Discard the rest of the line

std::string name;
std::getline(std::cin, name);    // Now works correctly
```

> [!NOTE]
> A plain `std::cin.ignore( )` removes only **one** character. If the user typed `25 abc`, the leftover ` abc\n` would still be waiting for `std::getline`. The form above discards the entire rest of the line.

> [!WARNING]
> **cin + getline mixing issue:** When you use `std::cin >> ` before `std::getline( )` a leftover `'\n'` character sits in the input buffer. `std::getline( )` reads it immediately and skips the actual input. Fix this by calling `std::cin.ignore( )` after any `std::cin >> ` before a `std::getline( )`. Note that `std::cin.ignore( )` discards only one character, so it is not enough if extra characters follow the number (e.g., `42abc`). To discard everything up to the newline, use `std::cin.ignore(std::numeric_limits<std::streamsize>::max(), '\n');` (requires `#include <limits>`).

```cpp
int age;
std::cin >> age;
std::cin.ignore();                // Discard the leftover '\n'

std::string name;
std::getline(std::cin, name);    // Now works correctly
```

## Input Validation & Stream States
`std::cin >> x` **fails** when the input cannot be converted to `x`'s type, for example when the user types `abc` for an `int`. When that happens:

1. `std::cin` enters a **fail state**.
2. Every later input operation is **silently ignored** until the state is cleared.
3. The offending characters **stay in the buffer**.
4. The target variable is set to `0` (C++11 and later).

| Member / expression       | Meaning                                                          |
| ------------------------- | ---------------------------------------------------------------- |
| `std::cin.fail( )`             | `true` if the last input operation failed                        |
| `std::cin.clear( )`            | Reset the stream back to a good state                            |
| `std::cin.ignore(n, delim)`    | Discard up to `n` characters, stopping after `delim`             |
| `std::cin.eof( )`              | `true` if the end of the input was reached                       |
| `if (std::cin >> x)`           | The stream converts to `bool`: `true` if the read succeeded      |

### The Standard Validation Loop

```cpp
#include <iostream>
#include <limits>
int main() {
    int age;

    std::cout << "Enter your age: ";
    while (!(std::cin >> age) || age < 0) {
        std::cout << "Invalid input. Enter a non-negative whole number: ";
        std::cin.clear();                                                   // 1. reset the fail state
        std::cin.ignore(std::numeric_limits<std::streamsize>::max(), '\n'); // 2. discard the bad line
    }
    std::cin.ignore(std::numeric_limits<std::streamsize>::max(), '\n');     // discard leftover input

    std::cout << "Age: " << age << "\n";
    return 0;
}

/* Sample run:
Enter your age: abc
Invalid input. Enter a non-negative whole number: -5
Invalid input. Enter a non-negative whole number: 25
Age: 25
*/
```

The condition checks two different things: `!(std::cin >> age)` catches a **type** failure, and `age < 0` catches an invalid **value**.

> [!WARNING]
> Do both steps, in this order. If you skip `std::cin.ignore`, the bad characters are never removed and every read fails immediately, so the loop runs forever. If you call `std::cin.ignore` before `std::cin.clear`, it does nothing, because a stream in a fail state ignores all operations.

> [!NOTE]
> If the input itself ends (Ctrl+D on Linux/macOS, Ctrl+Z on Windows), `std::cin >> age` fails permanently and the loop above never exits. Programs that must handle this should also check `std::cin.eof( )` and stop.

> [!TIP]
> A more robust alternative is to read the whole line with `std::getline( )` into a `std::string` and then convert it yourself (see 2.7). That approach is cleaner once you know exceptions.

## Formatted Output with `<iomanip>`
The `<iomanip>` header provides manipulators to control how output is formatted.

```cpp
#include <iostream>
#include <iomanip>
int main() {
    double price = 9.5;

    std::cout << fixed << setprecision(2) << price << std::endl;        // Output: 9.50
    std::cout << setw(10) << "Score: " << setw(5) << 100 << std::endl;  // Output: Score: 100

    return 0;
}
```

| Manipulator      | Effect                                      |
| ---------------- | ------------------------------------------- |
| `fixed`          | Use fixed-point notation for floats         |
| `setprecision`   | Show 'n' digits after the decimal           |
| `setw(n)`        | Set minimum field width for the next output |
| `left` / `right` | Align text within the field width           |
| `boolalpha`      | Print `true`/`false` instead of `1`/`0`     |
