## Overview
C++ handles console input and output through **streams** - abstract flows of data. The standard streams are provided by the `<iostream>` header.

| Stream | Direction | Purpose                       |
| ------ | --------- | ----------------------------- |
| `cout` | Output    | Print to the console          |
| `cin`  | Input     | Read from the keyboard        |
| `cerr` | Output    | Print errors (unbuffered)     |
| `clog` | Output    | Print log messages (buffered) |

## Output with `cout`
The `<<` operator (stream insertion) pushes data into the output stream.

```cpp
#include <iostream>
using namespace std;

int main ( ) {
	int age = 21;
	string name = "Krex";
	
	cout << "Name: " << name << endl;
	cout << "Age: " << age << endl;
	
	// Chaining multiple outputs
	cout << "Name: " << name << ", Age: " << age << "\n";
	
	return 0;
}
```

### `endl` vs `"\n"`
| `endl`                               | `"\n"`                                   |
| ------------------------------------ | ---------------------------------------- |
| Inserts newline + **flushes** buffer | Inserts newline only                     |
| Slightly slower                      | Faster (preferred in loops/heavy output) |

> [!NOTE]
> **Prefer \n over endl:** `endl` flushes the output buffer on every call, which is expensive in loops or high-frequency output. Use `"\n"` unless you specifically need to force a buffer flush.

## Input with `cin`
The `>>` operator (stream extraction) reads data from the keyboard into a variable.

```cpp
#include <iostream>
using namespace std;

int main ( ) {
	int age;
	string name;
	
	cout << "Enter your name: ";
	cin >> name;
	
	cout << "Enter your age: ";
	cin >> age;
	
	cout << "Hello, " << name << "! You are " << age << " years old." << endl;
	
	return 0;
}
```

> [!WARNING]
> **cin stops at whitespace:** `cin >>` reads only until the first space or newline. It will **not** capture a full name like "John Doe" - it stops at "John".
>

## Reading Full Lines with `getline( )`
Use `getline( )` to read an entire line including spaces.

```cpp
#include <limits>

int age;
cin >> age;
cin.ignore(numeric_limits<streamsize>::max(), '\n');   // Discard everything up to and including '\n'

string name;
getline(cin, name);                    // Now works correctly
```

> [!NOTE]
> A plain `cin.ignore( )` removes only **one** character. If the user typed `25 abc`, the leftover ` abc\n` would still be waiting for `getline`. The form above discards the entire rest of the line.

> [!WARNING]
> **cin + getline mixing issue:** When you use `cin >> ` before `getline( )` a leftover `'\n'` character sits in the input buffer. `getline( )` reads it immediately and skips the actual input. Fix this by calling `cin.ignore( )` after any `cin >> ` before a `getline( )`. Note that `cin.ignore( )` discards only one character, so it is not enough if extra characters follow the number (e.g., `42abc`). To discard everything up to the newline, use `cin.ignore(numeric_limits<streamsize>::max(), '\n');` (requires `#include <limits>`).

```cpp
int age;
cin >> age;
cin.ignore( );                         // Discard the leftover '\n'

string name;
getline(cin, name);                    // Now works correctly
```

## Input Validation & Stream States
`cin >> x` **fails** when the input cannot be converted to `x`'s type, for example when the user types `abc` for an `int`. When that happens:

1. `cin` enters a **fail state**.
2. Every later input operation is **silently ignored** until the state is cleared.
3. The offending characters **stay in the buffer**.
4. The target variable is set to `0` (C++11 and later).

| Member / expression       | Meaning                                                          |
| ------------------------- | ---------------------------------------------------------------- |
| `cin.fail( )`             | `true` if the last input operation failed                        |
| `cin.clear( )`            | Reset the stream back to a good state                            |
| `cin.ignore(n, delim)`    | Discard up to `n` characters, stopping after `delim`             |
| `cin.eof( )`              | `true` if the end of the input was reached                       |
| `if (cin >> x)`           | The stream converts to `bool`: `true` if the read succeeded      |

### The Standard Validation Loop

```cpp
#include <iostream>
#include <limits>
using namespace std;

int main( ) {
	int age;

	cout << "Enter your age: ";
	while (!(cin >> age) || age < 0) {
		cout << "Invalid input. Enter a non-negative whole number: ";
		cin.clear();                                              // 1. reset the fail state
		cin.ignore(numeric_limits<streamsize>::max(), '\n');      // 2. throw away the bad line
	}
	cin.ignore(numeric_limits<streamsize>::max(), '\n');          // drop any leftover input

	cout << "Age: " << age << "\n";
	return 0;
}

/* Sample run:
Enter your age: abc
Invalid input. Enter a non-negative whole number: -5
Invalid input. Enter a non-negative whole number: 25
Age: 25
*/
```

The condition checks two different things: `!(cin >> age)` catches a **type** failure, and `age < 0` catches an invalid **value**.

> [!WARNING]
> Do both steps, in this order. If you skip `cin.ignore`, the bad characters are never removed and every read fails immediately, so the loop runs forever. If you call `cin.ignore` before `cin.clear`, it does nothing, because a stream in a fail state ignores all operations.

> [!NOTE]
> If the input itself ends (Ctrl+D on Linux/macOS, Ctrl+Z on Windows), `cin >> age` fails permanently and the loop above never exits. Programs that must handle this should also check `cin.eof( )` and stop.

> [!TIP]
> A more robust alternative is to read the whole line with `getline( )` into a `string` and then convert it yourself (see 2.7). That approach is cleaner once you know exceptions.

## Formatted Output with `<iomanip>`
The `<iomanip>` header provides manipulators to control how output is formatted.

```cpp
#include <iostream>
#include <iomanip>
using namespace std;

int main ( ) {
	double price = 9.5;
	
	cout << fixed << setprecision(2) << price << endl;        // Output: 9.50
	cout << setw(10) << "Score: " << setw(5) << 100 << endl;  // Output: Score: 100
	
	return 0;
}
```

| Manipulator      | Effect                                      |
| ---------------- | ------------------------------------------- |
| `fixed`          | Use fixed-point notation for floats         |
| `setprecision`   | Show 'n' digits after the decimal           |
| `setw(n)`        | Set minimum field width for the next output |
| `left` / `right` | Align text within the field width           |
| `boolalpha`      | Print `true`/`false` instead of `1`/`0`     |
