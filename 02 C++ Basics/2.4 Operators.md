## Overview
Operators are symbols that instruct the compiler to perform specific operations on values (operands). C++ has a rich and powerful set of operators that span arithmetic, logic, comparison, and memory manipulation.

## 1. Arithmetic Operators
Use to perform standard mathematical calculations.

| Operator | Meaning        | Example  | Result |
| -------- | -------------- | -------- | ------ |
| `+`      | Addition       | `5 + 3`  | `8`    |
| `-`      | Subtraction    | `5 - 3`  | `2`    |
| `*`      | Multiplication | `5 * 3`  | `15`   |
| `/`      | Division       | `10 / 3` | `3`    |
| `%`      | Modulo         | `10 % 3` | `1`    |

> [!WARNING]
> **Integer Division:** When both operands are integers, `/` performs **integer division** - the decimal part is truncated, not rounded.
> `10 / 3` → `3`, not `3.33`
> To get a decimal result, at least one operand must be a `double`: `10.0 / 3` → `3.333...`

## 2. Assignment Operators
Used to assign or update values in a variable.

| Operator | Meaning                        | Example  | Equivalent to |
| -------- | ------------------------------ | -------- | ------------- |
| `=`      | Assign value                   | `x = 5`  | `Assign 5`    |
| `+=`     | Add and assign                 | `x += 3` | `x = x + 3`   |
| `-=`     | Subtract and assign            | `x -= 3` | x = x - 3     |
| `*=`     | Multiply and assign            | `x *= 3` | `x = x * 3`   |
| `/=`     | Divide and assign              | `x /= 3` | `x = x / 3`   |
| `%=`     | Modulus (remainder) and assign | `x %= 3` | `x = x % 3`   |

## 3. Increment & Decrement Operators
Shorthand to add or subtract 1 from a variable.

```cpp
int x = 5;

// Prefix: increment / decrement first, then use the value
cout << ++x << endl;                 // Output: 6, x is now 6
cout << --x << endl;                 // Output: 5, x is now 5

// Postfix: use the value first, then increment / decrement
cout << x++ << endl;                 // Output: 5, x becomes 6 after
cout << x-- << endl;                 // Output: 6, x becomes 5
```

> [!NOTE]
> **Prefix vs Postfix:** In isolation (`x++` on its own line), there is no difference. The distinction only matters when the expression is used as part of a larger statement or assignment.

## 4. Comparison (Relational) Operators
Return a `bool` result: `true` or `false`.

| Operator | Meaning                  | Example  | Result  |
| -------- | ------------------------ | -------- | ------- |
| `==`     | Equal to                 | `5 == 5` | `true`  |
| `!=`     | Not equal to             | `5 != 3` | `true`  |
| `>`      | Greater than             | `5 > 3`  | `true`  |
| `<`      | Less than                | `5 < 3`  | `false` |
| `>=`     | Greater than or equal to | `5 >= 3` | `true`  |
| `<=`     | Less than or equal to    | `5 <= 3` | `false` |

> [!WARNING]
> `=` is **assignment** (sets a value). `==` is **comparison** (checks equality). Writing `if (x = 5)` instead of `if (x == 5)` is a classic and dangerous bug - it assigns 5 to x and always evaluates to `true`.

## 5. Logical Operators
Combine or invert boolean expressions.

| Operator | Meaning     | Example            | Result  |
| -------- | ----------- | ------------------ | ------- |
| `&&`     | Logical AND | `true && false`    | `false` |
| `\|\|`   | Logical OR  | `true  \|\| false` | `true`  |
| `!`      | Logical NOT | `!true`            | `false` |

### Short-Circuit Evaluation
C++ stops evaluating a logical expression as soon as the result is determined.
* `false && anything` → immediately `false`, right side skipped.
* `true || anything` → immediately `true`, right side skipped.

This is useful for safety checks (e.g., check if a pointer is not null before dereferencing it).

## 6. The Ternary Operator
A compact one-line alternative to a simple `if/else`.

```cpp
// Syntax: condition ? value_if_true : value_if_false
int a = 10, b = 20;
int max = (a > b) ? a : b;
cout << "Max: " << max << endl;

string status = (age >= 18) ? "Adult" : "Minor";
```

## 7. Bitwise Operators
Bitwise operators work on the individual **bits** of integer values. They are used for flags, masks, binary protocols, hardware registers, and compact data storage.

| Operator | Name        | Rule                                       | Example (`a = 1100`, `b = 1010`) | Result                                       |
| -------- | ----------- | ------------------------------------------ | -------------------------------- | -------------------------------------------- |
| `&`      | AND         | 1 only if **both** bits are 1              | `a & b`                          | `1000` (8)                                   |
| `\|`     | OR          | 1 if **either** bit is 1                   | `a \| b`                         | `1110` (14)                                  |
| `^`      | XOR         | 1 if the bits **differ**                   | `a ^ b`                          | `0110` (6)                                   |
| `~`      | NOT         | Flips every bit                            | `~a`                             | All bits inverted (`~12` is `-13` for `int`) |
| `<<`     | Left shift  | Moves bits left, fills with 0 (×2 per shift)   | `1 << 3`                     | `8`                                          |
| `>>`     | Right shift | Moves bits right (÷2 per shift)            | `16 >> 2`                        | `4`                                          |

Each binary operator has a compound form: `&=`, `|=`, `^=`, `<<=`, `>>=`.

### Literals and Printing Bits

```cpp
#include <bitset>

unsigned int a = 0b1100;              // binary literal (C++14) = 12
unsigned int b = 0b1010;              // 10
int big = 1'000'000;                  // digit separator (C++14) for readability
int hex = 0xFF;                       // hexadecimal = 255

cout << bitset<8>(a & b) << "\n";     // 00001000
cout << bitset<8>(a | b) << "\n";     // 00001110
cout << bitset<8>(a ^ b) << "\n";     // 00000110
```

> [!NOTE]
> `bitset<N>` is used here only to print a value as binary digits. It is a full STL class covered later.

> [!WARNING]
> A literal with a leading zero is **octal**: `077` is 63, not 77.

### Common Bit Idioms
`n` is the bit position, counting from 0 at the right.

```cpp
unsigned int flags = 0;

flags |= (1u << n);                      // set bit n
flags &= ~(1u << n);                     // clear bit n
flags ^= (1u << n);                      // toggle bit n
bool isSet = (flags & (1u << n)) != 0;   // test bit n

bool isEven = (x & 1) == 0;                      // lowest bit decides odd/even
bool isPowerOfTwo = x > 0 && (x & (x - 1)) == 0; // a power of two has exactly one 1-bit
```

### Practical Example: Permission Flags
Several on/off options stored in one integer:

```cpp
constexpr unsigned int READ    = 1u << 0;     // 001
constexpr unsigned int WRITE   = 1u << 1;     // 010
constexpr unsigned int EXECUTE = 1u << 2;     // 100

unsigned int perms = READ | WRITE;            // 011 - combine flags with |

if (perms & WRITE) {                          // test a flag with &
	cout << "Can write\n";
}

perms |= EXECUTE;                             // 111 - add a flag
perms &= ~WRITE;                              // 101 - remove a flag
perms ^= READ;                                // 100 - toggle a flag
```

> [!WARNING]
> **Precedence trap:** comparison operators bind *tighter* than `&`, `^`, and `|`.
> ```cpp
> int y = 6;
> if (y & 1 == 0) { }        // parsed as y & (1 == 0) -> y & 0 -> always false (wrong!)
> if ((y & 1) == 0) { }      // correct
> ```
> Always put bitwise sub-expressions in parentheses. For the same reason write `cout << (a & b)`, not `cout << a & b`.

> [!WARNING]
> **`&` is not `&&`.** `&&` is *logical* (truthiness, with short-circuiting). `&` is *bitwise* (combines individual bits, no short-circuiting). For example, `2 && 1` is `true`, but `2 & 1` is `0`.

> [!IMPORTANT]
> Shifting by a negative amount, or by an amount greater than or equal to the type's bit width, is **undefined behavior**. Prefer `unsigned` types for bit manipulation, and write `1u << n` instead of `1 << n` so the shifted value is unsigned.

> [!NOTE]
> `<<` and `>>` are the same symbols as the stream operators from 2.3. For integers they shift bits, while for `cout` / `cin` they insert and extract data. The meaning depends on the operand types (operator overloading is covered later).

## 8. Operator Precedence (Key Rules)
Operators follow a strict order of evaluation, similar to BODMAS/PEMDAS in math.

```
Higher precedence (evaluated first):
( )                    → Parentheses
x++, x--               → Postfix increment/decrement
++x, --x, !, ~, -x     → Prefix increment/decrement, logical NOT, bitwise NOT, unary minus
*, /, %                → Multiplication, Division, Modulo
+, -                   → Addition, Subtraction
<<, >>                 → Bit shift (and stream insertion/extraction)
<, >, <=, >=           → Comparison
==, !=                 → Equality
&                      → Bitwise AND
^                      → Bitwise XOR
|                      → Bitwise OR
&&                     → Logical AND
||                     → Logical OR
?:, =, +=, -=, ...     → Ternary and assignment (lowest)
```

> [!NOTE]
> Don't rely on memorized precedence rules for complex expressions. Parentheses make intent explicit, improve readability, and eliminate bugs.
> `result = (a + b) * (c - d);` is always clearer than `result = a + b * c - d;`
